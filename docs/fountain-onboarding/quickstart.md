# Fountain Quickstart (New User)

Use this checklist to create and prep your first Show safely.

## 1. Create a Show by Duplicating an Existing Show

1. Find a similar show. Choose a recent one with similar venue or series. 
2. Edit that show and click `Duplicate Event`.
3. Enter the date and time of the first performance.
4. Enter the title in the `H1` field using the Source field, so no extra HTML is pasted in.
5. Make sure `Display in Section > Events` and `Hide from On Demand > Yes` are selected.
6. If the H1 title is very long or contains special characters/formatting, enter a clean short slug in `Overwrite Slug`.
7. Click `Duplicate`.
8. The page may show an error, but if you go to `Fountain > Shows` and sort by `Date Created > Descending`, your show should be there.
9. Make sure to check that anything from the previous show you don't need (examples: ticketing links, Fast Track "sold out" tag, Related Shows, Conversational Dates, h2 subtitles) is deleted.

3. Complete date, description, and button URL. 
4. Set venue map and organization.
5. Upload image, save, then click to "Set Title/Caption/Credit" to add caption/credit.
6. Confirm all right-rail controls.
6. Add tags (`Free`, `Family`, venue, series, genre as applicable).
7. Preview on correct template URL.
8. Keep invisible until approved.




## 4. Set Right-Rail Controls
1. Add relevant tags (Free, Family, venue, series, genre).
1. Visibility: keep it set to Invisible until you are ready to launch.

1. `Display in Section`: set to `Events` for live events.
2. `Is Featured`: keep `No`.
3. `Hide from On Demand`: set `Yes`
4. `Hide from Calendar`: generally `No`.
5. 'Event Type': ignore this.
5. `Is off-site`: generally set to 'Yes'.
6. Hide Event to Calendar: generally set to Display. If you want to hide the "Save to Calendar"feature for any reason, click Hide.
7. Disable Link - generally set to No.
8. Hite FT Email Form : generally set to Display.
9. Requires Email signup: generally set to No.
10. Registration Required: generally set to No
11. Learn More - generally set to Display.

Genre: generally ignore, since genres are set by tags now. if the genre is wrong though, change it to the right one or to n/a.
Artist Links: ignore.
Resources: ignore.
Series Label: generally set to Live Performance.
Importer controls: generally ignore.


## 5. Preview Before Launch

1. Save content.
2. Re-open and click Preview.
3. If template is wrong, adjust URL pattern:
- LC Presents events: `http://preview.lincolncenter.org/series/lincoln-center-presents/<your-page-slug>`
- Summer in the City: `http://preview.lincolncenter.org/series/summer-for-the-city/<your-page-slug>`



## 7. Final Pre-Publish Check

- Content copy reviewed
- Image/crop appropriate
- Links tested
- Visibility still `Invisible`
- Stakeholder approval received
- Then switch visibility for launch
