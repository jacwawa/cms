Quickstart (New User)

Create and prep your first Show safely.

Overview Quickstart Workflows Troubleshooting Snippets Photo Guidelines Launch Checklist

1. Create a Show by Duplicating an Existing Show

  1. Find a similar show. Choose a recent one with a similar venue or series.
  2. Edit that show and click Duplicate Event.
  3. Enter the date and time of the first performance.
  4. Enter the title in the H1 field using the Source field, so no extra HTML is pasted in.
  5. Make sure Display in Section > Events and Hide from On Demand > Yes are selected.
  6. If the H1 title is very long or contains special characters/formatting, enter a clean short slug in Overwrite Slug.
  7. Click Duplicate.
  8. The page will show an error, but if you go to Fountain > Shows and sort by Date Created > Descending, your show should be there.
  9. Remove anything copied over from the previous show that is not needed (for example: ticketing links, Fast Track "sold out" tag, Related Shows, Conversational Dates, H2 subtitles).

2. Edit the Show Content

  1. Fill Title Block fields (H3, H1, H3_2).
  2. Complete date, description, and button URL.
  3. Set venue map and organization.
  4. Upload image, save, then click Set Title/Caption/Credit to add caption/credit.
  5. Confirm right-rail controls.
  6. Add tags (Free, Family, venue, series, genre as applicable).
  7. Preview on the correct template URL.
  8. Keep the show invisible until approved.

3. Set Right-Rail Controls

  1. Visibility: keep Invisible until launch.
  2. Display in Section: set to Events for live events.
  3. Is Featured: keep No.
  4. Hide from On Demand: set to Yes.
  5. Hide from Calendar: generally No.
  6. Event Type: ignore.
  7. Is off-site: generally Yes.
  8. Hide Event to Calendar: generally Display. Use Hide only when you need to remove the Save to Calendar option.
  9. Disable Link: generally No.
  10. Hide FT Email Form: generally Display.
  11. Requires Email signup: generally No.
  12. Registration Required: generally No.
  13. Learn More: generally Display.

Additional control guidance:

  • Genre: generally ignore because genres are now set by tags. If it is wrong, correct it or set to n/a.
  • Artist Links: ignore.
  • Resources: ignore.
  • Series Label: generally set to Live Performance.
  • Importer controls: generally ignore.

4. Set Right-Rail Controls

  1. Display in Section: set to Events for live events.
  2. Is Featured: keep No unless required.
  3. Hide from On Demand: set Hide for live events.
  4. Enable Add to Calendar: generally Enable.
  5. Visibility: keep Invisible until approval.
  6. Add relevant tags (Free, Family, venue, series, genre).

4. Preview Before Launch

  1. Save content.
  2. Re-open and click Preview.
  3. If template is wrong, use the right preview pattern:
  • Atrium: http://preview.lincolncenter.org/venue/atrium/<your-page-slug>
  • Summer in the City: http://preview.lincolncenter.org/series/summer-for-the-city/<your-page-slug>

5. Final Pre-Publish Check

  • Content copy reviewed
  • Image/crop appropriate
  • Links tested
  • Visibility still Invisible
  • Stakeholder approval received
  • Then switch visibility for launch
